# AGENTS.md

This repo packages and releases Rolestash; it contains no application code.

- Application changes belong in [SHINO-01/rolestash](https://github.com/SHINO-01/rolestash) (branch `dev`), never in `source/`.
- Don't bump the `source` submodule by hand; the Release workflow pins released tags only.
- `CHANGELOG.md` entries are generated by the pipeline; edit wording afterwards if needed, never remove entries.
- Changing `policy/manifest-policy.json` changes what the extension may access: justify it in `store/listing.md` in the same PR.
- Tooling: `npm test` (Node ≥22.18, no build step). Keep workflows least-privilege, actions pinned to SHAs, and untrusted values out of `run:` scripts (use `env:`).
