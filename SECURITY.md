# Security policy

Report vulnerabilities privately via
[GitHub private vulnerability reporting on the source repo](https://github.com/SHINO-01/rolestash/security/advisories/new).
Only the latest release on the Chrome Web Store is supported.

Verify a release package's provenance:

```bash
gh attestation verify rolestash-<version>-chrome.zip -R SHINO-01/rolestash-extension
```
